## Task What is IoT

Domains and included areas:

- Smart Home – home automation, energy, security
- Industrial IoT (IIoT) – manufacturing, monitoring, predictive maintenance
- Healthcare IoT – wearables, remote patient monitoring
- Smart cities
- Actor/Sensor networks

Commonly used (data) protocols:

- MQTT – lightweight pub/sub, low bandwidth, constrained devices
- CoAP – REST-like protocol over UDP, low-power networks
- HTTP

Typical devices (appliance or micro controller):

- ESP32 – Wi-Fi/Bluetooth microcontroller, common for prototyping
- Raspberry Pi – single-board computer, gateway/edge processing

Benefits:

- Automation – reduced manual work
- Remote monitoring – real-time data access
- Efficiency – optimized resource usage (energy, time)
- Cost reduction – predictive maintenance, fewer failures
- Scalability – easy expansion of systems
- Convenience – smarter homes, cities, services

Challenges:

- Security – vulnerable devices, attack surface
- Privacy – sensitive data collection
- Interoperability – incompatible standards/devices
- Scalability – managing many devices
- Reliability – network failures, latency
- Maintenance – updates, device lifecycle management

IoT applications have the potential to solve lots of real-world problems. And there are very clever/out-of-box applications of IoT. It is everywhere.
